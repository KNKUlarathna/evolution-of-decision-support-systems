# Literature review matrix: 27 references

[Download the Excel workbook](https://raw.githubusercontent.com/KNKUlarathna/evolution-of-decision-support-systems/paper-downloads/revised-paper/literature-matrix/DSS_27_Reference_Literature_Matrix.xlsx) · [Download CSV](https://raw.githubusercontent.com/KNKUlarathna/evolution-of-decision-support-systems/paper-downloads/revised-paper/literature-matrix/DSS_27_Reference_Literature_Matrix.csv)

Prepared from all **27 references in the supplied `review-revised.pdf`**, using the ten columns and styling of the supplied literature-matrix example. Rows follow the manuscript’s reference numbering.

The workbook contains:

- **27-Paper Matrix**: Author, Year, Title, Problem, Method, Dataset / Tools, Key Findings, Limitations, Future Work, Source URL.
- **Sources and Access**: source versions, evidence locators, links to the 23 PDFs found in GitHub, and SHA-256 hashes of inspected PDFs. References [3]–[6] use complete archival/publisher copies not found in the checked repository collection.
- **Research Notes**: study-design boundaries and guidance on interpreting the matrix.

“Author-stated” and “Author-discussed” distinguish source statements from “Inferred” limitations and “Suggested” future research. Conceptual/review papers are not assigned invented experimental datasets. Reported numerical results retain their historical settings and are not pooled across studies.

The CSV contains the main table. [evidence-register.json](evidence-register.json) provides the same content and its supporting source register in a machine-readable format. The supplied manuscript and source PDFs have not been modified.

Prepared 21 October 2026. This is a bibliography-based literature matrix, not a newly conducted systematic search or meta-analysis.
